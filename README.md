# Platform Service

> A shared infrastructure or runtime service consumed by multiple application components. Allocated to OpenDEAM v0.8.0 as dea:entity-platform-service (class alias PS; layer L5; building_block L5-infrastructure). This catalogue owns platform service records; vendor products named in evidence are corroborating sources only and are never canonical (G-12). Re-pointed from the information-system-service identity by CR-ISS-CAT-02 (D-7 disposition 2026-11-12); information system service records remain owned by dea-catalog-information-system-services.

## What this catalogue is

The owning catalogue for platform service records: shared infrastructure
or runtime services consumed by multiple application components, per the
OpenDEAM v0.8.0 allocation of `dea:entity-platform-service` (layer L5,
building_block L5-infrastructure).

## What this catalogue is not

Boundaries are governed by the root model entity definitions and the
sibling `catalog_repo` allocations; anything outside this entity type
belongs to its owning catalogue. Information system services,
integration interfaces and APIs are separate entities with their own
catalogues.
